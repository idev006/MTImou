# Legacy Archive

This folder contains historical or experimental files that are **not part of the
current supported production path**.

Examples:

- relay / P2P-era experiments
- Rust probe experiments
- OpenAPI proof-of-concept tools
- one-off troubleshooting helpers
- old batch launchers that were replaced by the stable direct-runtime flow

The supported production path is now:

- `run_control_panel.bat`
- `run_camera_stable.bat`
- `run_multi_camera_stable.bat`
- `run_system_health_check.bat`
- `run_resilience_smoke.bat`

Use these archived files only for historical reference or controlled forensic
debugging.
